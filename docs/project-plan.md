# Project Plan

## Phase 00 - Repository Setup

Create the local repository structure and protect private source materials.

## Phase 01 - Source Inventory and Profiling

Build and run reproducible analysis scripts to inspect schemas, row counts, nulls, duplicates, candidate keys, date ranges, and potential relationships.

## Phase 02 - Data Findings and Data Model

Document validated source findings and propose a data model supporting daily Customer Lifetime Value and the secondary business requirements.

## Phase 03 - Architecture and Solution Design

Draft the AWS architecture, including ingestion, PySpark transformation, storage, encryption, scheduling, monitoring, and failure/reload handling.

## SME Approval Gate

Obtain written SME approval before creating AWS pipeline resources.

## Implementation Phases

The remaining build phases will be finalized after SME approval so that the implementation matches the approved architecture.
